# Dulce Palladar

Site de cafeteria com cardápio, cadastro e login de usuários, feito em PHP e MySQL.

## Tecnologias
PHP (PDO), MySQL, HTML, CSS e JavaScript.

## Como executar
1. Instale o XAMPP (Apache e MySQL) e coloque a pasta em `htdocs`.
2. Importe `dulce_palladar.sql` no MySQL.
3. Se necessário, defina as variáveis `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASS` e `DB_NAME` (padrão: localhost, 3306, root, senha vazia).
4. Acesse `http://localhost/dulce-palladar/`.
